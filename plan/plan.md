# Plan: ChatGPT-style chat UI (React + Vite)

## Goal
Clone the look and main screens of chatgpt.com as a new website, informed by studying the public page and JS/CSS of chat.classgrid.in. Rebuild the chat page UI (sidebar, chat area, input box) with React + Vite using fake data.

## Steps
1. **Download** the public page and its JS/CSS assets from chat.classgrid.in into the project.
2. **Study** the downloaded JS bundle — list main screens, components, and API calls (using helper agents).
3. **Scan** for keys/secrets — report only, never copy them.
4. **Scaffold** a React + Vite project.
5. **Build** the chat UI: sidebar, chat area, input box (fake data, no real API calls).
6. **Run** the dev server in the background, verify it works, and show proof.
